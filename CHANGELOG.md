# Changelog

## 1.0.0

First public release.

- Tabbed pages with 1 to 6 columns. Drag tabs to reorder; drop widgets on a tab to move them.
- Links widgets in list or icon view, with sections (headings and dividers), A–Z sort per section and bulk paste.
- Search widgets with per-widget engine choice, a configurable built-in engine list and user-added engines. Nothing is sent until Enter.
- Notes widgets with autosave and spellcheck off.
- Drag and drop for widgets and links, written from scratch with no libraries.
- Backgrounds: built-in images, uploads re-encoded to strip metadata, darken and blur, light or dark widgets.
- Backup and restore to one file. A backup status in the top bar brightens as un-backed-up changes age.
- Export and import of single pages and widgets. Import of browser bookmark HTML files.
- A library of ready-made widgets kept in JSON files.
- Filter with keyboard shortcuts. Layout lock.
- Built-in user guide with drop-in screenshot placeholders.
- Strict Content-Security-Policy, no-referrer, no DNS prefetch and no favicons. Server configs for Apache/LiteSpeed, IIS, nginx, Netlify and Cloudflare Pages.
